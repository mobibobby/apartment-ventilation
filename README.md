# Вентиляция в квартире

Интерактивная теоретическая модель воздухообмена в квартире: бризеры, вентиляторы, вытяжка, окна и кондиционеры, ускоренный таймлайн на 4 часа.

Открыть: https://mobibobby.github.io/apartment-ventilation/

Это упрощённая многозонная модель по чертежам и паспортам оборудования, без замеров. Допущения перечислены на самой странице.
